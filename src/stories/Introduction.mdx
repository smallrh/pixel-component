## ✨ 特性一览

- **🎮 像素美学** — 纯色描边 + `image-rendering: pixelated`，搭配等宽像素字体，还原 8-bit 质感
- **⚡ React 19 & TS 6** — 泛型组件类型推断、`ref-as-prop`（无 forwardRef 类型退化）、ESM 优先
- **♿ WCAG 2.1 AA** — 触摸目标 ≥ 44×44、ARIA APG 键盘交互、`role="alert"` 错误提示、焦点陷阱
- **📦 按需引入** — `exports` 按组件拆包 CSS：`import "react-ui-pixel/Button/style.css"`
- **🧩 受控 + 非受控** — 所有表单组件统一 `isControlled` 模式，`value` / `defaultValue` 双栈
- **🛡️ ErrorBoundary** — 渲染异常优雅降级，附单元测试
- **📚 Storybook 文档** — 每个组件独立 story，Controls 实时调参 + Autodocs 自动生成

## 🚀 快速开始

```bash
npm install react-ui-pixel clsx
```

```tsx
import { Theme, LocaleProvider, ConfigProvider, Button, Input } from "react-ui-pixel";
import "react-ui-pixel/style.css";

export default function App() {
  return (
    <LocaleProvider>
      <ConfigProvider>
        <Theme>
          <Button variant="primary">Hello Pixel</Button>
          <Input placeholder="Type something..." />
        </Theme>
      </ConfigProvider>
    </LocaleProvider>
  );
}
```

## 📖 约定

- 组件使用 **`ref` as prop**（非 `forwardRef`）以保留泛型类型推断
- 全局 CSS 全部以 `.pixel-*` 前缀作用域，不污染宿主样式
- 弹层组件必须提供 `open`（受控）+ `onOpenChange`（回调）
- 列表行项目使用 `React.memo` + 自定义 `areEqual` 优化重渲染
- 废弃 API 通过 `deprecated()` 工具在开发环境打印警告（如 Tooltip/Popover `visible` → `open`）
